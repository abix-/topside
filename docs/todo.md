# topside open issues

v1: a loop that is FUN for one hour and worth repeating once (leave bunker, explore, fight, loot, craft, repeat, storm resets). A row is v1 if the player notices it in the first hour and would quit without it.
v2: depth systems that make the loop rich (factions, trading, tech tree, biomes, weather, RPG).
v3: polish and endgame (NPC memory, vehicles, GPU simulation, quality/named uniques/work board/chronicle).
