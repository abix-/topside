# topside

A standalone post-apocalyptic survival game, built on the modforge crate.

You wake up in a bunker after the end of something. You know nothing. Go.

The design docs and the todo are pages in the operator's onelog notebook, in
its topside section (moved from docs/ on 2026-11-19): start at
topside-onboarding. A doc the code's comments name as `<name>.md` is the
page `topside-<name>`; an episode is `topside-episode-<name>`, a reality
`topside-reality-<name>`. docs/changelog.md stays here.
